# Surya Prasanth G — Portfolio

Personal portfolio site: **https://surya-prasanth-dev.netlify.app**

A single-page site that introduces me, my skills and my projects, with a downloadable resume. It includes a small interactive terminal (type `help`, `about`, `skills`, `projects` or `contact`).

## Projects featured

- **FreshCart – Grocery Web Application** (Java 17, Spring Boot 3, MySQL/H2, JUnit 5, Docker)
  Live: https://grocery-web-app-fb3j.onrender.com · Code: https://github.com/suryaprasanth740/grocery-web-app
- **PortfolioHub – Developer Portfolio Builder** (React 18, Firebase, Tailwind CSS, Vite)

## Built with

- HTML, CSS and vanilla JavaScript in one file (`index.html`), no build step
- Google Fonts: Chakra Petch, IBM Plex Sans, JetBrains Mono
- Hosted on Netlify

## Run it locally

Open `index.html` in any browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Drag this folder onto https://app.netlify.com/drop, or connect this repository to Netlify with no build command and `.` as the publish directory.
